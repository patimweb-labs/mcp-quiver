# 21 – Verwaltung (Vue): Anmeldung, Benutzer, Gruppen aus Entra

Nach 20. Anmeldeseite: „Mit Microsoft anmelden“ (nur wenn eingerichtet) und Root (E-Mail, Passwort); kein Feld für einen Schlüssel mehr. Sitzung nur über Cookie, **nichts** in localStorage. 401 → Anmeldeseite mit Rücksprung (nur eigene Pfade). Kopf: Name, Rolle, Abmelden.
Neue Seiten: **Benutzer** (Name, E-Mail, Rolle, Gruppen, Geräte, Stand der Prüfung; Admin ernennen/entziehen, sperren, jetzt prüfen, löschen – mit Rückfrage), **Prüfspur**. Gruppen-Dialog: Entra-Gruppen zuordnen (aus gesehenen Ids oder Id einfügen, Anzeigename). Geräte: Besitzer. „Gerät einbinden“ (Codes) nur ohne Entra; sonst Erklärung, wie der User sich am Gerät anmeldet. Drei Themes, Parität, Tastatur, vitest, Bilder.
